# Phase 2.4 — UI polish checklist

This release is a UI-focused update to Phase 2.3B. It does not alter localStorage keys, recipe data, or nutrition calculations.

1. Export your JSON backup before updating GitHub Pages.
2. Upload every file, including `phase24.css` and `phase24.js`.
3. Hard-refresh once (or close/reopen the installed PWA) to activate the new service worker.
4. Open every tab and confirm all workouts, food logging, and meal planning still work.
5. Meal Planner: use the Pantry / Recipes / Weekly plan / Grocery list quick navigation.
6. Open a recipe and confirm ingredients, servings, cooking instructions, and cooking time work.
7. Edit pantry quantities, generate meals, adjust portions, and confirm the grocery list updates.
8. Test keyboard Tab navigation and visible focus indicators.
9. Test narrow-screen layout on iPhone/Android and reduced-motion settings.
10. Refresh and verify your data remains.

Static syntax and archive integrity checks do not replace real browser/device tests.
