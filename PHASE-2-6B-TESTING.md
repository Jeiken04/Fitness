# Phase 2.6B — reliability
Export a backup before updating. Close all app windows after an update is downloaded, then reopen. Check Settings > App reliability. Test offline after installation on each device. Test main tabs using arrows, Home and End; check boxing mini-tabs. Start each timer, background the app for 30 seconds, return and verify elapsed time. Test pause/resume and skip. Background audio and timers after OS termination are not guaranteed. Verify saved workouts and backup restore on a disposable test profile. No storage schema changes. Error status is local and does not automatically repair failures. Performance changes reduce timer DOM writes and scroll updates; no benchmark claims.
