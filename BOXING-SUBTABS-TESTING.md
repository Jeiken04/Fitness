# Boxing true mini-tabs — test checklist

1. Back up your data before replacing GitHub Pages files.
2. Open Boxing. Quick Log should be visible and the other six sections hidden.
3. Select each mini-tab and confirm only its section is visible.
4. On mobile, swipe the horizontal mini-tab strip to access all seven tabs.
5. Keyboard: Tab into strip, use left/right arrows and Home/End to switch sections.
6. Under Programs, load a session: Boxing Studio must become visible automatically.
7. Run a timer, navigate to another boxing mini-tab, and return; check timer behavior.
8. Refresh; verify all saved boxing, nutrition, pantry, and Apple Health data remains.
9. Test offline after first online visit to allow the updated service worker to cache.
