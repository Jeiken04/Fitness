# Phase 3.0A — Unified analytics
Open Progress, select 7 or 30 days, or choose custom dates (maximum 366 days). Verify against saved training, food, weight and activity records. Training counts distinct dates per category, including quick checklist entries and journal entries; multiple sources on the same date are not added together. Food averages use logged days only; Apple Health averages use imported day aggregates, which may include zero steps when other activity was imported. Weight change uses first and last recorded weights in range. No new storage keys. Check empty data, invalid dates, mobile layout, keyboard controls and offline reload after service worker activation. Run `node --test tests/*.test.cjs` for automated checks. Physical device testing remains pending.
